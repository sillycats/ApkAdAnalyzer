功能特性

从字节码到原生库的多维扫描，覆盖广告植入的每一处藏身之地。

高速多模式匹配

自研 Aho-Corasick 自动机，字节字母表单遍扫描同时命中全部特征，性能出众。

18 类特征全覆盖

SDK 包名、类名、方法、权限、URL、View、Activity、Service、Receiver、资源、布局、assets 等。

AXML 深度解析

直接解析二进制 Manifest 与布局字符串池，准确提取组件与权限。

Flutter 应用适配

解析 lib/(ABI)/libapp.so，识别 Flutter / Dart 内嵌广告字符串特征。

离线加密特征库

77 家厂商 / 5100+ 条特征随包内置，混淆加密、原生库解密，明文不外泄。

一键导出配置

命中结果聚合为与 ad_patterns.json 格式一致的配置，支持复制或保存。

技术架构

无需反编译的字节级扫描内核，配合自研解析器与多语言 UI 基础设施。

🔍 分析内核

  • 匹配引擎Aho-Corasick 自动机，256 进字节字母表
  • AXML 解析自研解析器，提取类名 / 权限名 / 布局元素
  • Flutter 检测扫描 libapp.so 内嵌广告字符串
  • 大小写折叠ASCII 不敏感，内存占用更低

🧩 应用体验

  • 明暗双主题跟随系统 / 白天 / 夜间三种模式
  • 18 语言 UILocaleManager 动态切换，无需重启
  • 实时进度进度条 + 当前文件提示
  • 内置更新可配置清单地址与蓝奏云下载

🔐 特征安全

  • 混淆加密特征文件经混淆加密打包在 assets
  • 原生解密libnative_crypto.so 运行时解密调用
  • 密钥保护密钥与解密流程分布在 so 内
  • 离线加载全程本地，无任何网络请求

⚙️ 构建环境

  • 语言Kotlin（Android 7.0+）
  • SDKcompileSdk 34 / Build Tools 34
  • 构建JDK 17 + Gradle assembleRelease
